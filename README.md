# Pixel FX

Плагин Figma (ранее — PNG FX Tools).

Собран на [create-figma-plugin](https://yuanqing.github.io/create-figma-plugin/) (Preact + `@create-figma-plugin/ui`).

## Разработка

Требуется Node.js и десктопное приложение Figma.

```
npm install
npm run watch   # пересборка при изменениях
npm run build   # разовая сборка с проверкой типов
```

В Figma: Plugins → Development → Import plugin from manifest… → выбрать сгенерированный `manifest.json`.

## Статус

Все семь этапов плана готовы: каркас, мост данных, движок эффектов, интерфейс, пакетная обработка, производительность, пресеты и полировка. У всех семи модулей есть рабочие контролы, превью пересчитывается вживую с шторкой сравнения до/после на уменьшенной копии; тяжёлый расчёт (декодирование, конвейер, кодирование в PNG) выполняется в Web Worker, а не на главном потоке панели. «Применить» обрабатывает весь текущий выбор слоёв разом — с прогрессом, отменой, одним Undo на весь пакет и автоматическим обходом предела Figma в 4096 px. Пресеты сохраняются в `clientStorage` и доступны во всех файлах; настройки, с которыми был обработан слой, запоминаются на самом слое и подставляются при повторном выборе. Иконка и обложка для публикации лежат в `assets/`.
